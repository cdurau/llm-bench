# PulseBoard – Verhaltensregeln

## Zustandserhaltung
- Leistungen von anderen Tagen sind nicht überschrieben.
- Datum wird ISO YYYY-MM-DD gespeichert, der Vergleich funktioniert korrekt.
- Für zukünftige Tage ist kein Erledigt möglich.

## Ressourcen-Schutz
- Aktivitäten werden mit einem beständigen Kurznamen gespeichert
- Generische ID 27 Zeichen, 12-character name in storage
- Delete buttons werden über ein bestätigt.

## Modell-nach-Modell-Analysen werden NICHT ausgeführt.

## Zustandserhaltung (Erfüllung):
- Der Nutzer bestätigt den Status aktualisierter Daten, wird nicht durch das Löschen irreparabler Daten gelöscht.
