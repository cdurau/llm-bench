# AGENTS.md - PulseBoard

## Project Overview
PulseBoard is a minimalist personal daily overview PWA for tracking activities and habits.

## Project Structure
- `/src`: Application source code
- `/tests`: Automated tests
- `PLANNING.md`: Project roadmap and architectural decisions
- `MILESTONES.md`: Track progress and completed goals

## Instructions for Agents
- Maintain high code quality and strict TypeScript types.
- Ensure PWA capabilities (offline, installable).
- Follow the design guidelines established in `PLANNING.md`.
- Always run tests and production build before considering a task complete.
- Use the `jev` skill for critical architectural decisions.
- Keep documentation updated in the root directory.
