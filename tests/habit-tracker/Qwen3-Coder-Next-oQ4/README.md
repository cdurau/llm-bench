# Rhythm - Habit & Stimmungs-Tracker

Eine offlinefähige PWA für Habit- und Stimmungs-Tracking.

## Features

- **Heute-Screen:** Liste der Habits, per Tap abhaken, mit sanfter Animation
- **Habits verwalten:** anlegen, umbenennen, löschen, Emoji und Farbe wählen
- **Streaks:** aktuelle und längste Serie pro Habit
- **Stimmung:** einmal pro Tag Stimmung von 1 bis 5 auswählen
- **Woche-Screen:** Chart der letzten 7 Tage
- **Dark Mode:** folgt dem System, manuell umschaltbar
- **Offline:** komplett offline nutzbar nach erstem Laden
- **Leerzustände:** sinnvoll gestaltet

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- IndexedDB mit `idb`
- Recharts für Charts
- Vite PWA Plugin für offlinefähigkeit
